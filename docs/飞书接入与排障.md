# 飞书接入与排障

本文承接 [README](../README.md)「已知限制与飞书权限」的细节：配置脚本、回发正文渲染与历史修复、早期版本发布情况。`im:resource` 权限的两条速查仍以 README 那节为准；桥接机制实现见 [机制与实现详解](./机制与实现详解.md)。

## 配置脚本：skills/feishu-setup/scripts/create-bot.js

`skills/feishu-setup/scripts/create-bot.js` v6 提供：

- `configure` 子命令：给已有应用补权限/事件/回调，不动版本、不发布；
- `publish` 子命令：对外动作，必须显式 `--yes`；
- `--dry-run`：只演练不发写请求。

脚本用 `SCOPE_ALIASES` 把旧写法 `im:resource:upload` 自动归一化成 `im:resource` 并打 WARN；每次运行日志落在脚本同目录 `logs/create-bot-YYYYMMDD-HHmmss.log`。

## 回发正文渲染与历史修复

- **回发正文默认走飞书卡片**：正文用 `interactive` 卡片 + `lark_md` 渲染（1.5.20 起），设环境变量 `AIYAYI_FEISHU_MARKDOWN=text` 可一键回退纯文本。
- **正文首尾空白行已修**：飞书回复正文上下多出空行（无附件标记路径）的缺陷**已在 1.5.21 修**（坑 #72）——主修 `extractText(message).trim()` + 兜底 `stripAttachmentMarkers(text).trim()`。**只修首尾**；正文中**中间**的多余空行保持原样（那是另一个需求，尚未做）。
